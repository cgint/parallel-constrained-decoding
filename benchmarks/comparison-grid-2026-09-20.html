Verdicts

  1. RLCD's quality collapse is systematic, not noise. Three independent reps produce identical scores on every dataset (0.290 / 0.120 / 0.310) — the lowest cell in every dataset: b77 vs laya 0.345 / Jev 0.827 / LLM arms 0.842–0.860; goe vs Jev 0.229 / laya 0.378 / LLM arms 0.369–0.384; clinc vs laya 0.430 / Jev 0.727 / LLM arms 0.875–0.912. Its single-pass parallel decode is fast, but the selection strategy picks wrong tokens for these presets. Leading (untested) explanation: 77-way softmax over bare identifier tokens (gloss asymmetry).
  2. Thinking-ON is nearly free quality on banking77 (0.843 vs 0.842 at 5× latency) but matters on clinc150 (0.903 vs 0.875) and is neutral on goemotions (0.376 vs 0.369).
  3. Laya is the latency champion (31–126 ms p50, 6–25× faster than every LLM arm) with mid-pack quality; on goemotions it statistically matches the LLM arms (0.378 vs 0.376/0.384).
  4. DSPy on hosted Gemini 3.5 Flash-Lite is the quality leader on all three datasets (0.860 / 0.384 / 0.912) — same DSPy harness/schema as the local-qwen columns, different model — at 3–30× Laya's latency plus paid-API cost. The closed-API benchmark for quality.
  5. Best local arm: DSPy no-thinking (qwen 27B) — 0.842–0.875 on the two intent datasets at 168–222 ms, all on self-hosted hardware.
  6. Jev (TypeSafe API, column added 2026-09-23) is solid third on banking77 but never the top arm — 0.827 @687 ms beats local qwen (0.842 @168 ms) on nothing: qwen is both better and ~4× faster, and Gemini leads on quality. On clinc150 Jev clearly trails the LLM arms (0.727 vs 0.875–0.912); on goemotions it sits above local RLCD (0.229 vs 0.120) but clearly below the LLM arms (0.369–0.384). The closed API is a drop-in convenience, not a quality reference, on all three datasets. All Jev cells: n=600, 100% in-enum/in-schema across every request.

Limitations & validity labels

  • All runs n=600 (limit 200 × repetitions 3, seed-fixed selection); small-sample relative to production workloads.
  • RLCD's normalized candidate-slice softmax is not empirically calibrated (upstream docs); absolute scores should be read comparatively, not as probabilities.
  • Reference labels are dataset-provided; no independent human re-labeling was performed.
  • RLCD arms are three independent repetitions (rep1–rep3); identical quality scores across reps establish cross-run stability.
  • Gemini latency is measured from this host via API (network hop included); local arms have no network hop — cross-arm latency comparison is directional, not like-for-like.
  • The goemotions dspy thinking-ON reference run at n=200 (0.374, 6.7 s p50) was superseded by the n=600 re-run reported here.
  • Jev wall-clock is not recorded in its summary artifacts (only per-request client latency); the Jev column was added 2026-09-23 after the original 2026-09-21 grid, using the identical cohort. Its goemotions figure depends on the Noul threshold (0.5, untuned default) — see footnote ¹.
